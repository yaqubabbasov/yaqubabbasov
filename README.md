### 👨‍💻 About me

I'm an **Android Developer** focused on **clean architecture, scalable multi-module codebases and polished UI**. I turn Figma designs into production screens and keep codebases healthy with tests and CI.

- 🔭 Working on **Lets Speak Law** — a social platform for law students and legal professionals
- 🏗️ Multi-module architecture (`api` / `impl` feature modules), **MVI** with **Jetpack Compose**
- 🌐 Networking with **Retrofit + OkHttp**: token refresh, pre-prod / prod environments, API monitoring
- ✅ Unit tests, **ktlint** and **GitHub Actions** CI on every pull request
