### 🚀 Currently

**Lets Speak Law** — Android Developer
A social platform for law students and legal professionals: feed, posts with photo/video, profiles, search and messaging.

- Migrating the app to a **multi-module architecture** (`api` / `impl` feature modules connected through a mediator layer)
- Building new features in **Jetpack Compose** with a unidirectional **MVI** pattern (`State` / `Intent` / `Effect`)
- Network layer with **Retrofit + OkHttp**: token refresh, environment switching (pre-prod / prod), API monitoring
- **Build flavors** for pre-prod and prod, CI with **GitHub Actions** (ktlint + unit tests on every PR)
