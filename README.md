## Experience

### Android Developer — Lets Speak Law
*A social platform for law students and legal professionals*

- Drove the move from a single-module app to a **multi-module architecture** with `api` / `impl` feature modules and a mediator layer for navigation between features
- Built the **Profile** and **Search** flows as standalone Compose feature modules using a shared **MVI** base (`State` · `Intent` · `Effect`)
- Designed the networking layer: **Retrofit + OkHttp**, automatic token refresh, resilient session handling and runtime **pre-prod / prod environment switching**
- Set up **build flavors**, API monitoring for pre-prod builds and **GitHub Actions CI** (lint + unit tests)
- Delivered media features: photo/video posts with an in-app editor, **Media3** playback and **CameraX** capture
